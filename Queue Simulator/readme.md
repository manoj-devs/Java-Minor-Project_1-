# QueueSim | Core Java

A simple, menu-driven **Java console application** that simulates customer queue operations.

### Features
- Add and serve customers
- Track customer count
- Handle empty queue conditions
- Interactive menu using console input

### Tech Stack
**Java | Core Java | Scanner**

### Concepts Applied
Methods, return values, conditional statements, loops, and switch-case.

### How to Run

javac method2.java
java method2
